# DEPLOYMENT.md — Completely Free Native Render Deployment Guide ($0/month)

DRIP & RHYTHM deploys on **100% free native Render services** (no Docker, no paid worker, no paid add-ons) using [render.yaml](render.yaml).

---

## 1. Free Render Topology & Usage Limits (\$0/month)

| Resource | Render Type | Plan | Monthly Cost | Key Free-Tier Limits |
|---|---|---|---|---|
| `drip-and-rhythm-web` | Web Service (Node `26.13.0`, Next.js) | `free` | **\$0** | 512 MB RAM; spins down after 15 min idle (~30–60s cold start); 750 free instance hours/month across free web services |
| `drip-and-rhythm-api` | Web Service (Python `3.15.0`, Django + Gunicorn) | `free` | **\$0** | Same free web limits; protected by server-only `PROXY_SHARED_SECRET` (only `GET /api/health/` is directly reachable) |
| `drip-and-rhythm-db` | Managed PostgreSQL **18** | `free` | **\$0** | 256 MB RAM, 1 GB storage, private network only, **expires 30 days after creation** |

**Avoiding unexpected charges**:
- Use Render's **Hobby** workspace (\$0/month).
- Do **not** click "Upgrade" on any service, do **not** attach paid persistent disks, paid cron jobs, or paid workers, and keep billing auto-upgrade disabled.
- **Resend Free Tier**: 100 emails/day, 3,000 emails/month using verified domain `houseofzep.site` (`invitations@houseofzep.site`). Avoid unnecessary test sends.
- **Email retries while asleep**: Because there is no paid background worker, emails dispatch immediately after the claim/resend/reset DB transaction commits (`EMAIL_INLINE_DISPATCH=True`). Unattended background retries are **not** guaranteed while the free API service is asleep. If any job is pending or failed, an authenticated administrator can click **Retry Queue** on `/admin/dashboard` (calls `POST /api/emails/process-pending/`). Local development still uses `python manage.py process_email_jobs`.

> **Python runtime note**: If Render's native buildpack rejects `PYTHON_VERSION=3.15.0`, change `PYTHON_VERSION` on `drip-and-rhythm-api` to the latest supported `3.14.x` (Django 6.1 supports it) and redeploy.

## 2. Production Environment Variables

### Auto-Created Shared Group: `drip-and-rhythm-proxy-shared`
- `PROXY_SHARED_SECRET` *(auto-generated by Render; shared between `drip-and-rhythm-web` and `drip-and-rhythm-api` — never expose via `NEXT_PUBLIC_*`)*

### `drip-and-rhythm-web` (Next.js)
- `NODE_VERSION=26.13.0` *(from Blueprint)*
- `NEXT_TELEMETRY_DISABLED=1` *(from Blueprint)*
- `DJANGO_INTERNAL_API_URL` *(auto-linked from `drip-and-rhythm-api` host)*
- `NEXT_PUBLIC_SITE_URL` *(prompted)*: `https://drip-and-rhythm-web.onrender.com` (no trailing slash)

### `drip-and-rhythm-api` (Django)
- Blueprint-supplied: `PYTHON_VERSION=3.15.0`, `DJANGO_SETTINGS_MODULE=config.settings.prod`, `DJANGO_DEBUG=False`, `DJANGO_TIME_ZONE=Africa/Kampala`, `EMAIL_INLINE_DISPATCH=True`, `EMAIL_DELIVERY_MODE=resend`, `RESEND_FROM_EMAIL=invitations@houseofzep.site`, `RESEND_FROM_NAME=DRIP & RHYTHM`, `INITIAL_SUPERADMIN_NAME=Super Admin`.
- Auto-generated / linked: `DATABASE_URL`, `DJANGO_SECRET_KEY`, `TOKEN_ENCRYPTION_KEY` *(never rotate `TOKEN_ENCRYPTION_KEY` after launch)*.
- Prompted on apply:
  - `DJANGO_ALLOWED_HOSTS`: `drip-and-rhythm-web.onrender.com`
  - `DJANGO_CSRF_TRUSTED_ORIGINS`: `https://drip-and-rhythm-web.onrender.com`
  - `APP_BASE_URL`: `https://drip-and-rhythm-web.onrender.com`
  - `RESEND_API_KEY`: `re_...`
  - `RESEND_REPLY_TO_EMAIL`: organizer reply-to address
  - `RESEND_WEBHOOK_SECRET`: `whsec_...` *(can leave blank until webhook is created in step 4)*
  - `INITIAL_SUPERADMIN_EMAIL`: your production super admin email *(temporary — remove after first login)*
  - `INITIAL_SUPERADMIN_PASSWORD`: strong 12+ char password *(temporary — remove after first login)*

## 3. Deploy & Bootstrap Super Administrator

1. Push the repository to GitHub (the production DB starts completely empty — no local dev/test records are transferred).
2. In Render Dashboard → **New → Blueprint** → select your repository and `main` branch.
3. Verify all 3 resources show **Free (\$0/month)**, fill in the prompted values above, and click **Apply**.
4. On startup, `drip-and-rhythm-api` runs `migrate --noinput` → `bootstrap_production` (idempotently creates the singleton event + initial super admin if none exists; never resets existing passwords or event settings) → Gunicorn.
5. If Render assigned a suffix to your web URL (e.g. `drip-and-rhythm-web-xxxx.onrender.com`), update `NEXT_PUBLIC_SITE_URL`, `DJANGO_ALLOWED_HOSTS`, `DJANGO_CSRF_TRUSTED_ORIGINS`, and `APP_BASE_URL` to match and redeploy.
6. Sign in at `https://<your-web-url>/admin/login`.
7. **Immediately remove** `INITIAL_SUPERADMIN_EMAIL` and `INITIAL_SUPERADMIN_PASSWORD` from `drip-and-rhythm-api` → **Environment** in the Render Dashboard and save.

---

## 4. Resend Production Webhook

1. In Resend Dashboard → **Webhooks → Add endpoint**:
   - Endpoint URL: `https://<your-web-url>/api/webhooks/resend/`
   - Events: `email.sent`, `email.delivered`, `email.delivery_delayed`, `email.bounced`, `email.complained`
2. Copy the new webhook's signing secret (`whsec_...`) into `RESEND_WEBHOOK_SECRET` on `drip-and-rhythm-api` and save.
3. Do not modify existing domains, DNS records, or webhooks belonging to other projects.

## 5. Exporting Records Before the 30-Day Free PostgreSQL Expiration

Before the free PostgreSQL database expires (30 days after creation) — and right after the event on **5 December 2026**:
1. **Admin CSV Exports** (fastest): Sign in as super admin and download:
   - `/admin/invitations` → **Export CSV** (full guest list, references, statuses, email statuses)
   - `/admin/check-ins` → **Export CSV** (complete entrance attendance log)
2. **Optional Full Database Dump**: If you temporarily add your IP to the DB's Access Control list in Render, run `pg_dump "$EXTERNAL_DATABASE_URL" -Fc -f drip-and-rhythm-backup.dump`, then remove your IP from Access Control immediately after.
