## Self-Hosted Typography (OFL Licensed)
- **Anton**: Display titles, `DRIP & RHYTHM`, `INVITATION SECURED.`
- **WindSong**: Decorative `Private Party` script accents only
- **Montserrat**: Body copy, forms, buttons, tables, dashboard
- **Noto Sans**: International Unicode fallback across web, ReportLab PDFs, and Pillow PNGs

- `scroll-craft` dimensional planes used exclusively on `/`.
- Motion + native CSS only (`prefers-reduced-motion` respected globally); zero scroll hijacking; operational forms and `/admin/scanner` remain immediate and distraction-free.
